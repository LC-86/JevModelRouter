# 统一派发与隔离验证（Issue #11）

API 服务商上游请求（含其服务商／模型测试和手动测速）经过 `ConfigStore.dispatcher`。Debug、订阅模型测试和订阅手动测速先发送显式 `autojev/model/<id>` 或路由目标到本机网关，由网关复用普通生成的协议转换、订阅准入与适配器派发。订阅测试不接受 API Key，也不读取服务商 `base_url`；本机请求构造只允许回环网关地址。默认 `ApiDispatcher` 保留 API 上游请求、认证、协议转换、响应和流处理；可通过 `load_with_dispatcher` 替换外部派发实现。

Issue #24 的手动测速每模型运行 3 次流式探测，完成请求数和总数显示在界面，停止会丢弃尚未完成的请求。API 探测请求携带 24-token 输出上限；原生订阅适配器不接受未核验的 token 上限字段，因此订阅探测使用固定短提示，并在本机响应读取处限制为 64 KiB。订阅模型不进入自动测速。

此测试边界不执行订阅登录、真实账号或真实模型调用。生产订阅生成仍取决于同一准入门提供的身份、模型资格、协议能力和额度证据；未核验目标在派发前拒绝。隔离验收只使用本地假回调，不赋予真实订阅调用许可。

## 原生桌面验收

已有 pnpm 与 Rust 开发依赖的桌面环境中执行：

```sh
pnpm test:isolated
```

此命令构建前端与带 `isolation-check` 特性的开发二进制，启动独立 Vite、回环 HTTP 替身与原生桌面窗口，通过真实 React 控件和 Tauri IPC 验证：

- 服务商弹窗测试并保存、已保存服务商测试、模型行测试。
- 模型页面手动测速（三次受控探测）与三种下游协议的 Debug 流式响应。
- 临时 Codex Agent 配置连接、恢复、正常退出；保留自动重连偏好后重启也不自动重连。
- 重启读回服务商、虚构凭据、Agent 目录与测速记录；自动测速设置被强制关闭。
- 非回环目标、日常 Ollama 端口、回环重定向、未定义的订阅类型、带 API 身份的订阅条目、外部程序启动及目录外 Agent 配置被拒绝。
- 订阅服务商可添加保存并显示真实连接状态，未验证生成一律拒绝且替身从未收到订阅目标的请求（见 [订阅服务商入口与默认拒绝](subscription-entry.md)）。

替身接收端独立检查实际路径、认证、目标模型、消息内容和请求来源。驱动使用环境白名单，不继承 API Key、代理或客户端配置变量；不改 `HOME`。使用系统临时目录、OS 分配的网关／上游／Vite 端口，保留脱敏虚构报告、进程日志和请求记录。只回收本次启动的进程，不停止日常实例。

自动驱动仅在 `isolation-check` 构建中存在，并要求显式隔离参数；没有新增 HTTP 管理接口。普通开发／发布启动不执行驱动。

## 手动启动隔离窗口

先自行启动持有的 HTTP 回环替身，指定其准确端口，再执行：

```sh
root=$(mktemp -d -t autojev-isolated)
src-tauri/target/debug/autojev --autojev-isolated "$root" \
  --autojev-upstream http://127.0.0.1:实际替身端口 \
  --autojev-ui-url http://127.0.0.1:独立Vite端口
```

隔离参数只在开发构建可用。首次目录必须为空并位于系统临时目录；之后仅接受本应用的标记目录且拒绝符号链接。数据库、Agent 配置、实例锁和恢复记录均位于该目录，WebView 使用独立标识与隐私模式。禁止客户端执行／打开配置、自动网关启动、自动测速、已保存 Agent 重连和恢复 watchdog。使用页面按钮手动启动网关，后端持久化其实际监听端口。

所有 HTTP 派发仅允许指定替身 origin 和本实例网关端口，强制直连、禁用重定向，域名（含 localhost）不参与解析。代理设置、决策请求与 Debug 请求均不能扩大这一边界。独立替身不得指向真实模型或消费账号额度。

## 常规验证与证据范围

```sh
pnpm release:check
pnpm test
pnpm build
cargo test --locked --manifest-path src-tauri/Cargo.toml --lib
```

监听网关的 Rust 回归覆盖三种协议的九种源／目标组合，各含 JSON 和流式终态、认证、目标模型、工具内容与持久化；同时覆盖 Gemini 生成／流式桥接，以及隔离目标拒绝和禁止重定向。现有决策供应商、协议转换、错误和测速测试继续运行。

这些证据证明现有 API 与隔离替身的行为，不证明真实 OAuth、身份、订阅目录、额度、额外消费约束或订阅生成能力。真实验证按父规格由 Leo 手测，不在本票 Agent 执行范围。
